# yan (砚) downloads

Official installation packages and signed automatic-update feeds for **yan**, a native code editor.
The source repository remains private. This repository contains distribution information only;
automatically generated source archives contain this README, not the editor source.

Download installers from the [numbered releases](https://github.com/corn12138/yan-releases/releases).
Current previews support Apple Silicon Macs running macOS 13 or newer. Packages are ad-hoc signed
and are not Apple-notarized; the release notes include installation steps.

From v0.1.0-alpha.11, use **Help → 检查更新…** inside the application. Update archives are verified
against the embedded Ed25519 public key before installation. The `preview` and `stable` releases
hold channel manifests for the updater, not manual installers. No GitHub login is needed to download.

Each numbered release includes SHA-256 checksums and third-party license notices. The same notices
are included inside the application. Windows and Linux installers are planned but not available yet.
